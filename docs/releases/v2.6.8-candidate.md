# WordPaper 2.6.8 本地发布候选

此候选保留原生 Mac 工作台、Liquid Glass 和 Google 账号流程。账号服务新增 PostgreSQL 适配、SQLite 迁移与对账、数据库就绪检查、私有背景对象和备份工具。投产前仍需完成真实账号归属核对、云部署切换、第二台设备登录及正式发布。[迁移与恢复手册](../POSTGRES-MIGRATION.md)

离线桌面改动和补传队列在同一事务写入，连续离线编辑沿用最初的云端版本。多设备独立修改的设置字段、提醒、自定义词及不同词的复习排期可自动合并。遇到同条目的竞争修改，用户可以下载或恢复自己的冲突副本。

## 候选验证

已在 Apple Silicon Mac 上挂载三个安装包、核对资源清单并干净安装 ARM 版。使用 GitHub 正式版 2.6.7 自带的更新器，向隔离安装提供同一份 2.6.8 候选 DMG，完成实际挂载、文件替换、数据保留和新版本原生窗口启动。Intel 包内的 x64 Node 在 Rosetta 下通过运行检查。Google 跨端联调使用测试身份服务。

在 macOS 有 Xcode Command Line Tools 的环境中可重新构建。将官方 Node v24.19.0 Darwin arm64 和 x64 归档中的 bin/node 分别放入 scripts/node-dist/node-arm64、scripts/node-dist/node-x64，再准备两套语音运行时与 dmgbuild。

```bash
python3 scripts/build_speech_runtime.py
python3 -m venv scripts/.venv-build
scripts/.venv-build/bin/pip install dmgbuild
scripts/.venv-build/bin/python scripts/package_app.py
```
